# Визитка Lambeth

Статический сайт: HTML, CSS и JavaScript. Сборка и backend не нужны.

## Предпросмотр

В папке проекта запустите:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. При открытии index.html напрямую страница работает, но установка PWA и service worker требуют HTTPS или localhost.

## Данные компании

В начале `script.js` объект `BUSINESS`: название, описание, логотип, Instagram, WhatsApp, 2GIS и данные для контакта. `publicUrl` — постоянная HTTPS-ссылка опубликованной визитки. `orderUrl` — ссылка для заказа NFC-карты; без неё кнопка заказа скрыта.

После смены бизнеса также обновите статические SEO-метаданные в `index.html`, название приложения в `manifest.webmanifest` и иконки. Социальные сети обычно не исполняют JavaScript при построении превью.

## Публикация и NFC

Разместите все файлы проекта на статическом HTTPS-хостинге. Запишите в NFC-карту постоянную публичную ссылку. Содержимое можно менять без перезаписи карты. Адрес localhost недоступен с другого телефона; QR в локальном предпросмотре сообщает об этом.

После изменений увеличьте версию CSS/JS в index.html и список CORE_ASSETS и CACHE_NAME в sw.js. Текущая версия — v3.

## Адаптивность

Гибкая ширина до 480 px, отсутствие фиксированной высоты страницы, безопасные отступы для вырезов экрана, прокрутка модальных окон на низких экранах. На экранах уже 360 px второстепенные кнопки расположены вертикально. Установка и Web Share зависят от возможностей браузера; предусмотрены инструкции и копирование ссылки.
